# SEER

Code for **SEER: Source-Conditioned Emotion Enhancement via Retrieval for Cochlear-Implant Speech**.

SEER learns to select an emotional reference that helps a source utterance remain recognizable after cochlear-implant (CI) simulation. Reference-conditioned emotional voice conversion (EVC) enhances the source toward the selected expression, while the original speech is retained when no reference has positive predicted utility.

## Demo audio

Listen to the [audio examples](demo/README.md) comparing Source, Strong, JD-NMF, and SEER for Angry, Happy, and Sad. Each example includes clean speech and N4, N8, and N16 CI-simulated versions.

The examples were selected from listening-test cases where SEER improved emotion recognition across all three CI conditions. They use the original experiment audio.

## Environment setup

Use Python 3.12 and install the dependencies:

```bash
python -m pip install -r requirements.txt
```

Run the commands below from the SEER repository root unless stated otherwise.

## External models

Set up Maestro-EVC with Python 3.11 following its repository instructions. Prepare the other pretrained models using their providers' instructions, then configure their local paths in `configs/paths.sh`.

| Component | Project or model |
|---|---|
| Emotional voice conversion | [Maestro-EVC](https://github.com/truestar2001/MaestroEVC) |
| Speech emotion recognition | [Emotion2Vec+ Large](https://huggingface.co/emotion2vec/emotion2vec_plus_large) and [emotion2vec](https://github.com/ddlBoJack/emotion2vec) |
| Emotion features | [SpeechBrain emotion diarization](https://huggingface.co/speechbrain/emotion-diarization-wavlm-large) |

| Word error rate evaluation | [Whisper large-v3-turbo](https://huggingface.co/openai/whisper-large-v3-turbo) |

Maestro-EVC's additional model assets are described in its repository. Whisper is needed only for WER evaluation. Train the dataset-specific Maestro-EVC and SEER models using the steps below; trained checkpoints are not included.

## Dataset preparation

Download [RAVDESS speech audio](https://doi.org/10.5281/zenodo.1188976) and [ESD](https://github.com/HLTSingapore/Emotional-Speech-Data).

For RAVDESS, set `SEER_RAVDESS_RAW` to the directory containing `Actor_01` through `Actor_24`. For English ESD, set `SEER_ESD_RAW` to the directory containing speakers `0011` through `0020`, preserving their transcript files and emotion folders.

Run preprocessing for the dataset you want to use:

```bash
bash run.sh ravdess preprocess
bash run.sh esd preprocess
```

Preprocessing converts recordings to mono 16 kHz, extracts features, and writes split metadata and the `train.txt` and `dev.txt` lists used for EVC training. Outputs are stored under `SEER_RAVDESS_DATA` or `SEER_ESD_DATA`.

The experiments use these splits:

- **RAVDESS:** fold 0 assigns actors 4/12/13/23 to testing, 9/16/21/22 to development, and the remaining 16 actors to training.
- **English ESD:** within each speaker/emotion folder, the first 20 sorted recordings are development, the next 30 are test, and the remaining 300 are training.

## Maestro-EVC training

Train a separate Maestro-EVC model for each dataset using the [upstream training instructions](https://github.com/truestar2001/MaestroEVC) and the corresponding configuration in `configs/maestro/`. Both EVC models use Angry, Happy, Sad, Neutral, and Surprise.

| Setting | RAVDESS | English ESD |
|---|---:|---:|
| Training/development recordings | 576/144 | 15,000/1,000 |
| Batch size | 16 | 64 |
| Optimizer updates | 23,040 | 150,000 |
| Validation interval | 1,000 | 1,000 |

Copy the configurations to your model directories:

```bash
source configs/paths.sh
mkdir -p "$SEER_RAVDESS_MAESTRO_DIR" "$SEER_ESD_MAESTRO_DIR"
cp configs/maestro/ravdess.json "$SEER_RAVDESS_MAESTRO_CONFIG"
cp configs/maestro/esd.json "$SEER_ESD_MAESTRO_CONFIG"
```

Edit `input_training_file` and `input_validation_file` to point to the lists generated by preprocessing. Use these lists directly in the Maestro-EVC trainer, rather than creating another split. The trainer used in our experiments requires reading both lists explicitly and stopping both training loops at the requested update count. Save the final generator and set GPU visibility for your machine.

For RAVDESS:

```bash
(
  cd "$SEER_MAESTRO_ROOT"
  python train.py --config "$SEER_RAVDESS_MAESTRO_CONFIG" \
    --checkpoint_path "$SEER_RAVDESS_MAESTRO_DIR" \
    --training_steps 23040 --validation_interval 1000
)
```

For ESD:

```bash
(
  cd "$SEER_MAESTRO_ROOT"
  python train.py --config "$SEER_ESD_MAESTRO_CONFIG" \
    --checkpoint_path "$SEER_ESD_MAESTRO_DIR" \
    --training_steps 150000 --validation_interval 1000
)
```

Set the resulting generator checkpoint and matching configuration paths in `configs/paths.sh` before training SEER.

## SEER training and enhancement

Build the reference bank, train the retriever, and generate enhanced speech in that order.

For RAVDESS:

```bash
bash run.sh ravdess build-bank
bash run.sh ravdess train-seer
bash run.sh ravdess enhance
```

For English ESD:

```bash
bash run.sh esd build-bank
bash run.sh esd train-seer
bash run.sh esd enhance
```

The reference bank contains training recordings whose annotated emotion is recognized correctly in clean speech and the configured CI conditions. SEER samples source–reference pairs, evaluates their conversion outcomes, and uses the resulting utility targets to train the retriever.

| Setting | RAVDESS | English ESD |
|---|---:|---:|
| Retriever training/development sources | 384/96, Normal and Strong | 9,000/600 |
| Reference-bank conditions | Clean, N4, N8, N16 | Clean, N8 |
| Reference-bank size | 281 | 6,630 |
| Reward condition | N8 | N8 |
| Selected update in the paper | 96 | 360 |

Training selects `best.pt` using development-set N8 macro-F1. Enhancement uses this checkpoint to select the highest-utility reference and retains the source when no predicted utility is positive.

The enhancement commands produce the Table 1 test outputs: 48 RAVDESS Normal utterances, including both repetitions, and 900 English ESD utterances. SEER training and evaluation target Angry, Happy, and Sad.

Enhanced recordings are saved under `$SEER_RAVDESS_OUTPUT/audio/` or `$SEER_ESD_OUTPUT/audio/`. The accompanying `selections.csv` records the reference chosen for each source. Training settings are in `configs/seer/`.

Additional command options are available through:

```bash
python -m seer.train --help
python -m seer.enhance --help
```

## Evaluation

After enhancement, evaluate emotion recognition and intelligibility on the saved audio:

```bash
bash run.sh ravdess evaluate-ser
bash run.sh ravdess evaluate-wer

bash run.sh esd evaluate-ser
bash run.sh esd evaluate-wer
```

Both evaluators use the same enhanced recordings under Clean, N4, N8, and N16.

SER evaluation uses Emotion2Vec+ Large. Its scores are normalized over Angry, Happy, Sad, and Neutral before selecting the largest score. Macro-F1 averages the three target emotions; a Neutral prediction counts as a missed target.

WER evaluation uses Whisper large-v3-turbo with English transcription, greedy decoding, a maximum of 128 new tokens, and FP16 on CUDA. Reference transcripts come from the RAVDESS statements or ESD transcript files. Text is NFKC normalized, lowercased, and stripped of punctuation except apostrophes. Corpus WER divides the total substitutions, deletions, and insertions by the total reference word count.

Results are saved beneath `$SEER_RAVDESS_EVALUATION` or `$SEER_ESD_EVALUATION`:

| File | Contents |
|---|---|
| `ser/predictions.csv` | Source and SEER emotion predictions for each condition |
| `ser/metrics.json` | Macro-F1 in `selector[view].macro_f1`, as a fraction |
| `wer/utterance_wer.csv` | SEER transcripts and word-error counts |
| `wer/metrics.json` | Corpus WER for each condition |

The paper reports the following SEER results, in percentages:

| Condition | RAVDESS F1 | RAVDESS WER | ESD F1 | ESD WER |
|---|---:|---:|---:|---:|
| Clean | 100.00 | 0.35 | 99.11 | 7.13 |
| N4 | 80.13 | 2.08 | 68.23 | 16.62 |
| N8 | 85.56 | 1.39 | 68.75 | 10.00 |
| N16 | 95.82 | 1.04 | 82.06 | 8.48 |

Select checkpoints using the development set in a new run. Exact scores can vary with the training and numerical environment.

## CI simulation

The simulator adapts [Gaudrain's vocoder](https://github.com/egaudrain/vocoder) using pulse-spreading harmonic complex (PSHC) carriers. It processes mono 16-kHz audio through 22 CI24 bands spanning 188–7938 Hz, with half-wave rectification, 250-Hz envelope low-pass filtering, and N-of-M maxima selection at 900 Hz. N4, N8, and N16 select 4, 8, and 16 maxima from the same 22 bands.

Carrier phases and extraction offsets use seed `20260910`. Output RMS matches the input after filtering to the analysis frequency range, with no peak clipping or additional loudness floor. Settings are defined in `seer/ci.py`; the reported results concern this acoustic simulation.
